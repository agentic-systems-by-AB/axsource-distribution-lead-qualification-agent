## Trigger Definitions

Lead Qualification Trigger

Connector:

Microsoft Dataverse


Trigger type:

When row added, modified or deleted


Table:

Lead


Change type:

Added

Modified


Trigger columns:

Subject

Description

Company Name

Lead Source

Owner

Parent Account

Product Interest


Filtering rule:

Execute only when qualification-relevant fields change


Execution rule:

Ignore updates generated by qualification workflows to avoid loops

## Approval Workflow Design

Workflow:

Approval Workflow


Trigger:

Agent recommendation requiring human approval


Approval channels:

- Microsoft Teams adaptive card
- Dynamics 365 in-app confirmation


Approval payload:

- Lead name
- Qualification score
- Confidence score
- Recommended branch
- Recommended owner
- Channel conflict findings
- Credit findings
- Qualification narrative


Approval outcomes:

Approve

Reject

Request more information


Behavior:

Approve:

Continue downstream workflow


Reject:

Persist rejection and stop execution


Request more information:

Create seller task and pause workflow


Rule:

Approval is mandatory for all external or shared-data actions.
