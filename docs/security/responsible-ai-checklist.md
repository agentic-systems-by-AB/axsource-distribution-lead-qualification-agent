# Responsible AI Checklist

Status: Draft

Controls:

- Human approval required before external communication
- No autonomous email sending
- Confidence downgrade model enabled
- Seller override permitted
- Qualification rationale stored
- Audit history retained
- No hidden AI memory
- No AXSource-hosted customer data
- Customer data remains inside tenant
- Shared-data updates require approval

Autonomy model:

Autonomous qualification with human approval before external action

Risk controls:

High confidence:
Ready for seller approval

Medium confidence:
Surface missing evidence

Low confidence:
Request additional information
